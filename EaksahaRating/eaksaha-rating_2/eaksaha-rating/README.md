# ระบบประเมินความพึงพอใจพนักงานขายรถ EV — EAKSAHA GROUP

ระบบเว็บสำหรับให้ลูกค้าประเมินความพึงพอใจต่อพนักงานขาย (เซลล์) รถยนต์
รองรับ 9 แบรนด์: **DEEPAL · GEELY · AION · OMODA & JAECOO · WULING · CHERY · GWM · FORD · NISSAN**
(เพิ่ม/ลบแบรนด์ได้เองในเมนู "แบรนด์รถ")
ดีไซน์ธีมดำ-แดงสไตล์ Eaksaha Group ทั้งหน้าประเมินของลูกค้าและระบบหลังบ้าน

---

## คุณสมบัติหลัก

- **หน้าประเมิน (ลูกค้า)** เข้าผ่านลิงก์/QR ของเซลล์แต่ละคน ให้คะแนน 1–5 ระดับ กดปุ่มแล้วส่งทันที + ช่องข้อเสนอแนะ แสดงป้ายแบรนด์ที่เซลล์สังกัด (สีตามแบรนด์)
- **หลังบ้าน (ผู้ดูแล):**
  - แดชบอร์ด — คะแนนเฉลี่ยรวม, จำนวนรีวิว, รีวิววันนี้ + กราฟแนวโน้มที่เลือกช่วงเวลาได้ (7/30/90 วัน, 12 เดือน, ปีนี้, ทั้งหมด หรือกำหนดวันเอง มุมมองรายวัน/เดือน/ปี)
  - รายงานคะแนน — ตัวกรองครบในที่เดียว (ช่วงเวลา, แบรนด์, เซลล์, เฉพาะที่มีข้อเสนอแนะ) พร้อมแถบสรุปผลและกราฟกระจายคะแนน 1–5
  - จัดการพนักงานขาย — เพิ่ม/แก้ไข/ลบ, อัปโหลดรูป, เลือกแบรนด์สังกัด (1 คน 1 แบรนด์), สร้าง QR + ลิงก์ให้คะแนนอัตโนมัติ
  - จัดการแบรนด์ EV — เพิ่ม/แก้ไข/ลบ 8 แบรนด์ พร้อมกำหนดสีประจำแบรนด์
  - เปลี่ยนรหัสผ่าน, คู่มือการใช้งาน (อัปโหลด PDF), หน้าทีมผู้พัฒนา

---

## ความต้องการของระบบ

- PHP 7.4 ขึ้นไป (แนะนำ PHP 8.x) เปิด extension: `pdo_mysql`, `fileinfo`, `gd`/`getimagesize`
- MySQL 5.7+ หรือ MariaDB 10.3+
- เว็บเซิร์ฟเวอร์ Apache/Nginx (หรือ XAMPP/Laragon สำหรับทดสอบ)

---

## วิธีติดตั้ง

1. **นำไฟล์ทั้งหมดวางในโฟลเดอร์เว็บ** เช่น `htdocs/eaksaha-rating/`

2. **สร้างฐานข้อมูล** — นำเข้าไฟล์ `database.sql` ผ่าน phpMyAdmin หรือคำสั่ง:
   ```bash
   mysql -u root -p < database.sql
   ```
   สคริปต์จะสร้างฐานข้อมูล `eaksaha_rating` พร้อมตาราง แบรนด์ทั้ง 8 และผู้ดูแลระบบเริ่มต้นให้อัตโนมัติ

3. **แก้ไขการเชื่อมต่อฐานข้อมูล** ที่ `conn/config.php`
   ```php
   $db_host = 'localhost';
   $db_name = 'eaksaha_rating';
   $db_user = 'root';      // แก้ตามจริง
   $db_pass = '';          // แก้ตามจริง
   ```
   (ในไฟล์เดียวกันสามารถแก้ชื่อองค์กร/ฝ่าย ได้ที่ค่า `ORG_NAME`, `ORG_DEPT` ฯลฯ)

4. **ตั้งสิทธิ์โฟลเดอร์อัปโหลด** ให้เขียนได้ (บนโฮสต์จริง)
   ```
   admin/uploads/staff/     (รูปเซลล์)
   admin/uploads/login/     (รูปพื้นหลัง + โลโก้ login)
   admin/uploads/manual/    (ไฟล์คู่มือ PDF)
   ```
   ตั้งเป็น `755` หรือ `775`

5. **เข้าใช้งาน**
   - หลังบ้าน: `http://<your-domain>/eaksaha-rating/admin/login.php`
   - หน้าประเมินลูกค้า: เปิดจากลิงก์/QR ในหน้า "พนักงานขาย"

## การปรับแต่งเพิ่มเติม

- **โลโก้/พื้นหลังหน้า login** — วางไฟล์ในโฟลเดอร์ `admin/uploads/login/`
  - โลโก้: ตั้งชื่อ `logo.png` (หรือ .jpg/.webp)
  - พื้นหลัง: ไฟล์รูปชื่ออื่น (เช่น `bg.jpg`) จะถูกนำมาใช้เป็นภาพฝั่งซ้ายของหน้า login อัตโนมัติ
- **สีประจำแบรนด์** — ปรับได้ในเมนู "แบรนด์รถ EV" (มีผลกับป้ายแบรนด์บนหน้าประเมินและกราฟ)
- **ทีมผู้พัฒนา** — แก้รายชื่อได้ในไฟล์ `admin/developer.php` (ตัวแปร `$developers`)
